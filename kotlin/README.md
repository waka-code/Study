# 📚 Ruta de Aprendizaje Kotlin — de 0 a Senior/Staff

Plan de estudio por sesiones para convertirme en desarrollador **Kotlin Senior** (y evolucionar hacia Staff/Principal). Cada sesión es un bloque digerible: se estudia, se practican los ejercicios y luego se pasa a la siguiente.

> **Método:** una sesión a la vez → estudiar → hacer ejercicios → confirmar → siguiente sesión.

Un **Senior Kotlin** domina: Kotlin idiomático · Coroutines/Flow · Clean Code · Arquitectura · Testing · Performance · JVM · una rama fuerte (Backend o Android) · Code reviews · CI/CD · Cloud · Observabilidad · Seguridad.
