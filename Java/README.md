# Java — Ruta de estudio (Junior → Senior)

Estudio completo de Java organizado por **sesiones digeribles**. Cada sesión es un archivo con teoría, ejemplos prácticos, preguntas de entrevista y checklist. Se estudia una, se asienta, y se pasa a la siguiente.

> Meta: cubrir todo lo que se espera de un **Senior Java Backend Developer** (lenguaje + JVM + Spring + arquitectura + DevOps + rendimiento).
