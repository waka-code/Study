# AWS Managed Services

AWS Managed Services (AMS) es una oferta de AWS que gestiona operaciones operativas de infraestructura en nombre del cliente, aplicando las mejores prácticas de AWS y automatizando tareas repetitivas.

## Qué es AWS Managed Services

- AWS Managed Services administra de forma continua la infraestructura en AWS del cliente, incluyendo aprovisionamiento, gestión de cambios, seguridad, monitoreo e incidentes.
- Está diseñado para organizaciones que quieren ejecutar cargas de trabajo en AWS sin gestionar directamente la operación diaria de la infraestructura.
- AMS puede incluir operaciones sobre servicios como Amazon EC2, Amazon VPC, Amazon RDS, AWS IAM, AWS CloudTrail, AWS Config y otros componentes de red y seguridad.

## Cómo encaja en la arquitectura y ecosistema AWS

- AWS Managed Services amplía el ecosistema AWS al proporcionar un servicio gestionado para la operación de la nube, complementando servicios de infraestructura y de plataforma.
- Sirve como una capa de operaciones para empresas que desean un enfoque “operado por AWS” mientras mantienen control sobre arquitectura, gobernanza y cumplimiento.
- Se integra con AWS Well-Architected, AWS Control Tower y AWS Organizations para mantener consistencia en seguridad, gobernanza y gestión de cuentas.

## Casos de uso comunes

- Empresas que están migrando centros de datos a AWS y necesitan soporte operativo continuo.
- Organizaciones reguladas que requieren controles de seguridad, auditoría y gestión de conformidad.
- Equipos de TI que desean externalizar la gestión operativa de la infraestructura para enfocarse en el desarrollo de aplicaciones y la innovación.
- Clientes que necesitan escalabilidad operativa sin aumentar significativamente el personal de operaciones.

## Beneficios

- Operación automatizada y estandarizada según las mejores prácticas de AWS.
- Visibilidad centralizada de los recursos, conformidad y seguridad.
- Respuesta rápida a incidentes y gestión de cambios estructurados.
- Reducción de la carga operativa para los equipos internos de TI.

## Consideraciones

- AWS Managed Services es una oferta de servicio gestionado y puede implicar costos adicionales sobre la infraestructura AWS estándar.
- No es una solución para todas las cargas de trabajo; conviene evaluar si el nivel de control y personalización cumple con los requisitos del negocio.
- AMS está orientado a clientes que necesitan operación continua y soporte de nivel empresarial sobre su infraestructura en AWS.

## Relación con otros servicios de AWS

- AWS Managed Services se complementa con AWS Support y AWS Professional Services.
- Puede funcionar junto con AWS Control Tower para gobernanza de múltiples cuentas y con AWS Organizations para administración centralizada.
- Es compatible con AWS Security Hub, AWS Config y AWS CloudTrail para monitoreo y cumplimiento.
- Ayuda a cimentar operaciones seguras y confiables en arquitecturas basadas en AWS.
