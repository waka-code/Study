# AWS IQ

AWS IQ es un servicio de Amazon Web Services que conecta a clientes con expertos certificados en AWS para obtener ayuda bajo demanda.

## Qué es AWS IQ

- AWS IQ permite publicar solicitudes de proyecto, recibir propuestas de consultores y gestionar el pago dentro del entorno de AWS.
- Está orientado a empresas y equipos que necesitan apoyo puntual en áreas como arquitectura, migraciones, seguridad, DevOps, datos y soluciones específicas en la nube.
- Los expertos en AWS IQ son verificados por AWS y reciben calificaciones basadas en proyectos anteriores, disponibilidad y experiencia.

## Cómo encaja en la arquitectura y ecosistema AWS

- AWS IQ no es un servicio de infraestructura, sino un servicio de soporte profesional dentro del ecosistema AWS.
- Facilita la integración entre los clientes y los recursos humanos especializados que conocen los servicios AWS nativos y las mejores prácticas de arquitectura.
- Complementa otros programas de AWS como AWS Support, AWS Partner Network (APN) y AWS Professional Services.

## Casos de uso comunes

- Análisis de una arquitectura existente en AWS y recomendaciones de mejora.
- Diseño de soluciones escalables y seguras utilizando servicios como Amazon EC2, Amazon RDS, AWS Lambda, Amazon VPC, entre otros.
- Migración de aplicaciones a AWS o modernización de cargas de trabajo.
- Implementación de controles de seguridad, auditorías y cumplimiento normativo.
- Configuración de CI/CD, automatización con AWS CloudFormation, Terraform o AWS CDK.

## Beneficios

- Ayuda rápida sin necesidad de contratar personal a tiempo completo.
- Acceso a especialistas certificados en AWS para resolver problemas concretos.
- Gestión centralizada de solicitudes, propuestas y pagos.
- Permite escalabilidad de recursos humanos según necesidades puntuales del proyecto.

## Consideraciones

- AWS IQ es ideal para proyectos puntuales y trabajos de consultoría breve.
- No reemplaza un acuerdo de soporte técnico formal, pero sí puede ser un complemento para tareas especializadas.
- Es recomendable definir claramente el alcance del proyecto para recibir propuestas ajustadas a los requerimientos.

## Relación con otros servicios de AWS

- AWS IQ está alineado con las prácticas de Well-Architected al asesorar sobre confiabilidad, seguridad, eficiencia de rendimiento, optimización de costos y excelencia operativa.
- Se puede usar como apoyo para implementar soluciones basadas en AWS Managed Services y servicios de Partner Network.
- Es una vía para obtener asesoría práctica sobre el uso correcto de los servicios AWS dentro de una arquitectura de nube.
