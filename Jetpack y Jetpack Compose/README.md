# Jetpack y Jetpack Compose — Ruta de estudio (Junior → Senior/Staff)

Estudio completo del ecosistema Android moderno basado en **Jetpack** y **Jetpack Compose**, organizado por **sesiones digeribles**. Cada sesión es un archivo con teoría, ejemplos prácticos, diagramas y preguntas de entrevista. Se estudia una, se asienta, y se pasa a la siguiente.

> Prerrequisito recomendado: base de **Kotlin** (carpeta `kotlin/`). La Sesión 2 repasa el Kotlin *imprescindible para Compose* por si necesitas refrescar.

## Progreso

- [x] **Sesión 1 — Fundamentos**: qué es Jetpack, qué es Compose, paradigma declarativo, setup, primer `@Composable` → [sesion-01-fundamentos.md](sesion-01-fundamentos.md)
- [ ] Sesión 2 — Kotlin imprescindible para Compose (null safety, lambdas, scope functions, delegates, coroutines base)
- [ ] Sesión 3 — Composición y Recomposición (cómo piensa Compose por dentro)
- [ ] Sesión 4 — Estado en Compose (`remember`, `mutableStateOf`, `rememberSaveable`, State Hoisting)
- [ ] Sesión 5 — Layouts (Row, Column, Box) y Modifiers
- [ ] Sesión 6 — Listas: LazyColumn / LazyRow y rendimiento de listas
- [ ] Sesión 7 — Material 3 (Scaffold, TopAppBar, componentes, theming)
- [ ] Sesión 8 — Navigation Compose (rutas, argumentos, deep links)
- [ ] Sesión 9 — Side Effects (`LaunchedEffect`, `DisposableEffect`, `rememberCoroutineScope`, `SideEffect`)
- [ ] Sesión 10 — Estado avanzado (`derivedStateOf`, `produceState`, `snapshotFlow`, `CompositionLocal`)
- [ ] Sesión 11 — ViewModel + StateFlow + gestión de eventos (UI State / UI Events)
- [ ] Sesión 12 — Coroutines y Flow aplicados a Android
- [ ] Sesión 13 — Persistencia: Room y DataStore
- [ ] Sesión 14 — Networking: Retrofit, OkHttp, serialización, interceptores
- [ ] Sesión 15 — Inyección de dependencias con Hilt
- [ ] Sesión 16 — WorkManager y Paging 3
- [ ] Sesión 17 — Arquitectura: Clean Architecture, MVVM y MVI
- [ ] Sesión 18 — Modularización (feature/core/domain/data, version catalogs, convention plugins)
- [ ] Sesión 19 — Animaciones y gestos
- [ ] Sesión 20 — Testing (unit, Compose UI test, Turbine, fakes)
- [ ] Sesión 21 — Performance (recomposición, estabilidad, Baseline Profiles, Macrobenchmark)

> El orden puede reagruparse; algunas sesiones cortas se combinarán para no perder ritmo. Referencias base: documentación oficial de Android Developers, Kotlin Docs y el proyecto **Now in Android** (arquitectura moderna de Google).
